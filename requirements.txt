# 💡 Street Light Fault Register & Repair Tracker

## Project Overview

Street Light Fault Register & Repair Tracker is a Flask-based web application used to register, track, update, and manage street light complaints.

---

## Features

- Register Street Light Complaint
- Dashboard
- Search Complaint
- Filter by Status
- Edit Complaint
- Delete Complaint
- Update Status
- Pending Count
- In Progress Count
- Repaired Count
- SQLite Database

---

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
